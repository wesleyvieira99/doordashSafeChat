## Brand and icon guidance

- [Azure official architecture icon guidance](https://learn.microsoft.com/en-us/azure/architecture/icons/) allows documentation and architectural uses and asks that icons not be distorted or used as the creator's own product identity.
- [Google Cloud icon library](https://cloud.google.com/icons) distinguishes product icons from the cloud company wordmark.
- [GitHub brand toolkit](https://brand.github.com/foundations/logo) supplies official logo guidance.
- [Python community logos](https://www.python.org/community/logos/) provide the official brand files and trademark guidance.
- [TypeScript branding](https://www.typescriptlang.org/branding/) provides official file variants.
